Auspify – Landing Page

A modern, responsive landing page developed as part of the Week 1 Frontend Developer Task. This project focuses on creating an attractive user interface with clean styling, interactive elements, and a structured layout.
🚀 Features

- Responsive landing page design
- Hero section with call-to-action buttons
- About section
- Services section
- Modern styling and visual effects
- Interactive elements using JavaScript
- Smooth navigation between sections
🛠️ Technologies Used

- HTML5 – Page structure
- CSS3 – Styling, layout, and responsiveness
- JavaScript – Interactive functionality

📁 Project Structure

```text
Auspify_Week1_Landing_Page/
├── index.html
├── style.css
├── script.js
└── README.md
```

💻 How to Run the Project

1. Clone this repository or download the project files.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or run it using the Live Server extension.
4. Explore the landing page and its interactive features.

🎯 Objective

The objective of this task is to practice frontend development fundamentals, including HTML structure, CSS design, JavaScript interactions, and organizing project files.
